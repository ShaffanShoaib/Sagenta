# Create Common UI Components

## Description
Develop reusable UI components such as buttons, input fields, and modals, adhering to design guidelines.

## Acceptance Criteria
- [ ] A reusable `Button` component with different styles (primary, secondary, disabled) is available.
- [ ] An `Input` component supporting various types and basic validation styling is implemented.
- [ ] A basic `Modal` component with open/close functionality is created.
- [ ] Components are documented (e.g., Storybook) and styled consistently.
